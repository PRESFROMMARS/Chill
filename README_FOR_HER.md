# Chill · 打开就会用的小指南

**每天只记一句：先锁定，再巡航；手机提交成功并关闭应用后，最后安全恢复。**

## 第一次见面 · 只做一次

① **装好苹果驱动**

在 Windows 10 / 11 的 Microsoft Store 搜索并安装 Apple 官方的「Apple Devices（Apple 设备）」。
插上手机、解锁，在手机上选择「信任此电脑」并输入密码。
先确认 Apple 设备应用里能看见这台 iPhone，再打开 Chill。
[苹果的连接说明](https://support.apple.com/zh-cn/108392)

② **打开开发者模式**

手机进入「设置 → 隐私与安全性 → 开发者模式」，开启后按提示重启，再确认开启。
如果看不到这一项，请让帮你装软件的人完成开发连接与配对。
[苹果的开发者模式说明](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)

③ **安装或解压软件**

在 GitHub 仓库的 Releases 页面下载 `Chill-Setup.exe`，运行安装后，从开始菜单打开 Chill。
安装程序包含完整运行文件，不需要另外安装 Python。私有仓库需要先登录有访问权限的 GitHub 账号。

如果拿到的是免安装版：

把收到的 `Chill-Windows-Portable.zip` **全部解压**到一个好找的文件夹，再双击 `Chill.exe`。
Windows 询问是否允许更改设备时，确认这是你收到的这份软件，再点「是」。
`_internal` 文件夹是软件的一部分，要一直和 `Chill.exe` 放在一起。

```text
解压后的文件夹
├── Chill.exe          ← 双击这里
├── _internal         ← 留在这里
└── README_FOR_HER.md ← 这份说明
```

## 每天出发 · 1 → 2 → 3

先用**能传数据**的 USB 线连接手机。线材绑紧在支架上，接头留一点余量，避免晃动拉扯；
手机和线材远离摇步器底座磁铁。保持手机解锁，按界面逐项完成准备检查。
开跑前，从 iPhone 的多任务界面彻底划掉高德、百度、美团、微信等可能在后台使用定位的应用。

| 步骤 | 你要做的事 |
| --- | --- |
| **1 · 锁定起点** | 搜索学校、放大操场。第一次沿跑道点出至少三个锚点，拖动调整并保存。点击「1. 锁定操场起点」，认真确认七项检查。坐标发到手机后才开始 **5 秒**倒计时。看到就绪提示后，再打开手机应用和摇步器。 |
| **2 · 开始巡航** | 点击「2. 开始拟真巡航」。看里程与今日建议停表里程；绿色提示亮起后，到手机应用里完成提交。 |
| **3 · 安全恢复** | **先在手机里看到提交成功，再从手机后台彻底划掉运动应用，最后才点电脑上的「3. 安全结算并恢复」**。看到「恢复指令已发送」后，打开 iPhone 自带的「地图」，确认蓝点回到真实位置后再拔线或关窗口。若未恢复，请重启手机。 |

临时需要增加途经点：切到支线草稿，沿道路依次点选、拖动微调，将需要经过的点设为必经点。
金色虚线只是草稿；点击「确认切入支线」后才会生效。

中途想缓一缓，可点击「歇一下（切换慢走）」：会逐步转为慢走，约 40～60 秒后恢复，
也可点击「恢复慢跑」。切换期间按钮会暂时置灰。
达到目标里程后会持续慢走，里程和用时仍会增加。暂停慢走或收尾慢走时，可以点击「原地驻留（定点保活）」停下并保持当前位置，然后按第 3 步操作。

如果还没在手机上开始、提交失败或决定取消，先停止并关闭手机运动应用，再点「放弃本次未提交会话」，确认后选择「安全恢复定位」。

## 看不懂时 · 只看这里

- **显示「沙盒预览模式」**：现在只在电脑上预览，没有接管手机定位。检查数据线、信任提示、开发者模式和苹果驱动。
- **地图空白**：先检查电脑网络；地图瓦片需要联网。首次连接手机下载开发者资源也可能需要等待。
- **窗口空白或打不开**：请安装微软官方 [WebView2 Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)，再重新打开。
- **外部校时不可达**：人工确认电脑与手机显示的时间一致，再勾选时间检查。如果提示两者有偏差，打开 Windows「设置 → 时间和语言 → 日期和时间」，点「立即同步」后重新校验。
- **起点倒计时中断**：检查数据线和手机连接。选择「放弃本次未提交会话」并安全恢复定位，再重新锁定起点。
- **正在巡航关不掉窗口**：先完成上面的第 3 步。里程达到建议值后，也需要完成安全恢复。
- **提示「另一个程序实例正在运行」**：先关闭控制这部手机的另一个 Chill 窗口，再重试；不要同时打开两份。
- **提示上次定位未恢复**：连接上次使用的同一部手机，点击恢复定位，成功后再开始。
- **提示路线过长或过密**：缩短单圈或减少选点后重试；必经点仍会保留原坐标。
- **其他错误**：截图界面中的具体原因。也可以把 Windows 的 `%USERPROFILE%\Chill\last_session.log`
  或 macOS 的 `~/Chill/last_session.log` 发给维护者；文件最多 256KB，只保留近期故障摘要。

电脑上的预览里程不等于手机应用已成功记录；以手机应用实际显示为准。
